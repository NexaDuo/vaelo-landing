Perguntas frequentes

Preciso pagar para usar o IPCA?

Não. A correção pelo IPCA é grátis para sempre.

Quem do grupo precisa pagar?

Só uma pessoa. Ela libera o grupo para todos os membros.

O que acontece se eu cancelar?

O grupo volta ao limite grátis de 5 despesas novas por dia, e nada é apagado.

Meus dados ficam com vocês?

Não. Os lançamentos ficam nos aparelhos, cifrados de ponta a ponta. O servidor só repassa blocos cifrados e não consegue ler seu conteúdo.
